# VHA 工具 0.20.1（原生运行库仍为 0.20.0）

## 这是什么

这是 0.20.0 整理版的工具更新，不是丝袜隐藏补丁，也不是更换鞋模。
不修改原生 C++、SVS build13 渲染、Glass 手工 Heel=1.1、裸脚逻辑、OBody、主配置或已发布高度库。
最终 MO2 整理包复用 9a666b1 的已构建 DLL 0.20.0；Python 工具版本独立为 0.20.1。

## 已接入

1. `FeetH / HeelFeet / UBE_Feet / FemaleFeet` 作为候选名称，但名称不代表通过。
   必须是完整读取的 8837 顶点、16200 面，全部有序三角面索引的 SHA-256 必须符合已核验 UBE 参考域，
   且局部、蒙皮和有效父节点变换为核验坐标系。多个候选、未知拓扑、额外非零 preset 均拒绝。
   原 `Feet` 路径保持原有规则，包括原先可用的删减小组件匹配；不把鞋壳改名为 Feet。
2. SSE stream 100 的蒙皮分区读取支持多个分区及稀疏顶点映射。
   保留完整全局顶点数组，不将分区的 VertexMap 再套到本来已经是全局编号的三角面上。
   核对三角面副本、全局边界、分区映射、描述符；重复跨分区面、条带、非零 LOD、未知布局继续拒绝。
3. 原 `no-usable-Feet` 拆为 `no-reference-feet`、`geometry-read-error-no-reference` 和
   `reference-feet-not-validated` 等状态。详情中提供 `footReference`、`statusDetail` 和逐形状错误。
   模型读取成功不等于存在参考脚，更不等于配对高度或游戏画面已验证。
4. 保留路径记忆、直接编辑手工 JSON、筛选和高度库浏览。
   清单计数同时显示装备记录数和去重模型路径数，避免附魔/颜色变体看起来像大量独立坏模型。
5. 新增“仅复查问题鞋＋所选丝袜”，使用当前启用插件的获胜记录，仅读取明确范围的模型。
   必须先选择至少一件丝袜和平脚参考。结果写入独立 `feet-review-*` 子目录，
   不覆盖原全量目录或旧配对结果；计算只针对后续选中的新配对，现有增量发布器保留未选中的旧库成员。
6. 不可测鞋也可以带入手工编辑器，而不会因此被允许进入自动计算。
   “Witchy＋CPB 试调（未验证）”仅预填 `NoHeel=0, Heel=0.47` 和明确未验证备注；
   不自动保存，不复制 Agata 的 approval，不覆盖既有配对，不发布成自动测量结果。

## 样本覆盖与边界

实际收到的 Trainers、Ankle、Alicia 样本通过新参考脚选择，能够与原 CPB 计算并导出增量高度库。
另六个同名候选模型未收到原件；新版会在用户扫描时自行逐个核验，不能预先宣称全部通过。
Steel 和 Cyber Assasin 样本的几何现在能读取，但其中没有独立参考脚，仍不自动计算高度。
Witchy 的原件没有独立参考脚，也没有新造一只脚；0.47 只用于用户明确选择的试调。
不将 HH_OFFSET、鞋外观相似度或同模组关系直接当作形变系数的依据。
未启动用户的 MO2 或 Skyrim；任何 CI / 本地模型测量都不是实机视觉验收。

## 安装

退出游戏后将安装 ZIP 作为新 MO2 模组，例如 `VHA 0.20.1 Tools`，放在原 0.20.0 之后。
保留原 0.20.0 和其数据层启用，新包覆盖 DLL/工具但不覆盖主配置、用户配置或高度库。
本包 DLL 与原 0.20.0 字节相同。已有可选 Glass 私人资源保持原状态，不在本包中新增或移除。
不需要重新安装 SVS，不要启用旧 0.19.1 隐藏版本。

必须将 MO2 外部 Python 启动参数指向本新模组的物理文件：

    "D:\MO2\mods\VHA 0.20.1 Tools\tools\vha_offline.py" gui

继续使用已有 Python 3.12、通过 MO2 启动。不要只是覆盖左侧优先级而继续启动旧目录的 Python。
新窗口标题含“工具 0.20.1”；报告保留 `generatorVersion=0.18.0` 作为既有报告格式代际，
新增 `toolVersion=0.20.1` 标明实际工具版本，不破坏旧候选文件和原生库的兼容性。

## 不重扫全模型的使用方式

- 载入旧 `offline-catalog.json`。它仍可直接浏览，不会假装旧数据自动获得新几何。
- 在丝袜页选择要适配的丝袜，保留本人确认的平脚参考（原 Converse）。
- 点击“仅复查问题鞋＋所选丝袜”。会重新读取当前插件获胜记录，但不会扫描全部模型。
- 复查后选择新成为 measurable 的鞋与丝袜，计算所需配对，使用“保存所选到高度库”。
- 原有未选中的库分片和个人手工配置保留，不需要重算整个已完成高度库。

Witchy 手工试调：鞋页改为“全部状态”，指向准确 Witchy；丝袜页指向 CPB，点击试调按钮。
编辑器只填入字段。“应用此条到编辑区”仍未写文件，再点击“保存手工覆盖 JSON”才写入。
已有同一对条目会被重复校验阻止新增；请有意选择、编辑旧条目，不会无声覆盖。
保存/发布后在游戏中 `set VHA_Reload to 1`，关闭控制台等待游戏正常执行任务。

## 回退

退出游戏，停用新模组并把外部 Python 参数切回原 0.20.0 工具路径即可。
如自己保存过 Witchy 试调，在编辑器删除那条覆盖并重载，或恢复 `.json.bak`。
如发布过新高度库成员，停用工具包不会自动删除它们；保留发布前的数据备份用于完整回退。
安装本包本身不写入这些个人数据，也不进行安装后自动扫描或发布。
